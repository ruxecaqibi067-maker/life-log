# 生活随记 · Android 第一版

给自己使用的轻量生活记录 App，目标手机为荣耀 200 Pro。饮食、作息、运动共用一条时间线，以随手记录为核心。

**当前状态：需求、技术路线和分派文档已建立；尚未创建 Android 工程、编写 App 或生成 APK。** 本主管对话负责规划、协调、审查和验收，实现由用户在其他对话中按任务包完成。

## 第一版边界

- 饮食：一句文字或一张照片即可保存，饱腹感选填。
- 作息：「准备睡了／起床了」，支持跨日、午睡、补录和修改。
- 运动：跑步、力量及其他项目，允许自定义；一次训练可有多个动作，力量可选填每组重量与次数。
- 回顾：今天的时间线、按日期查看、编辑和删除。
- 数据：本地离线保存，完整备份导出和恢复，更新 App 后保留记录。

桌面组件、提醒、云同步、GPS 轨迹、AI、热量估算、训练计划和复杂统计放在后续版本。

## 仓库约定

- 此目录为独立本地 Git 仓库；未创建 GitHub 远程，也未上传任何内容。
- 默认按编号串行执行，一个工作目录同时只允许一个实现对话写入。
- 实现任务在各自分支完成并提交，主管验收后合入 `main`。需要并行时使用独立 worktree。
- 代码、文档、Gradle Wrapper 和后续 Room schema 纳入 Git；用户照片、备份、构建产物、签名密钥不纳入 Git。
- 开始写代码前阅读 [AGENTS.md](AGENTS.md)。构建命令将在 T01 真正建立工程后才能执行。
