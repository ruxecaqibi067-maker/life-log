## 实际交付

- 首页「记运动」进入真实训练编辑器。最少选择一个项目即可保存；支持重复添加同一项目、移除、上移/下移，使用各自稳定 UUID 区分条目。
- 复用 T07 的选择界面及新增项目后立即选中回调。项目选择器和编辑器分别持有 SavedStateHandle；训练草稿、选择界面开关、输入及排序能在短暂重建时恢复。保存期间禁用修改、返回和重复保存，失败保留草稿及 ID 供重试。
- 有氧提供选填时长和距离，其他类型提供选填时长；力量本包只需记录动作，未生成虚构组数。项目备注及整次训练备注均选填，上限各 1000 Unicode 码点。
- 距离使用 km，十进制精确转换为整数米；时长使用分钟，并提供选填的补充秒数（0–59），精确合成为整数秒。补充秒数保证既有任意秒数可无损查看/编辑，不将整数秒转换成循环小数分钟。两项时长输入全空时存 null；填写后的总时长须大于 0。距离留空为 null，填写后须大于 0。
- 默认完整发生时间为现在。日期、时间使用系统选择器，可补录，时区默认设备时区，编辑时沿用原记录时区。未修改日期时间时保留原秒、毫秒与偏移；修改时拒绝夏令时不存在时间，重复时间明确提供偏移选择。
- 首页「今日训练」单独列出当日训练，一场训练只显示一个摘要；点摘要查看详情、编辑或确认删除。入口「训练记录 / 补录」可切换日期、查看旧记录并进入录入。这里的新增仍默认当前时间，可在表单中选择补录日期。
- 详情按历史名称/类型快照及条目顺序显示项目。没有数值时显示「已记录此项目，训练量未填写」，不会显示 0 分钟、0 km 或编造组数。已有组数据会保留，详情可只读查看，逐组编辑仍留给 T09。
- 离开有修改的表单需确认放弃；删除需确认。保存及删除成功后依赖 Room Flow 更新列表和详情，不手工维护另一份记录。未保存表单不承诺跨强停或重启恢复。

- 沿用 `WorkoutRepository.saveWorkout(WorkoutDraft)`、`workout(id)`、`observeWorkout(id)`、`workoutsOn(localDate)`、`deleteWorkout(id)`；本包没有改 DAO、Repository、AppContainer、生产依赖、权限、实体、Room v1 schema 或备份格式。
- 新增、编辑、删除继续经过 `WriteCoordinator` 和既有 Room 事务。保存时整场 session/items/sets 及最近使用信息一起提交；删除/替换子项由外键级联删除组。测试在子项写入和删除阶段注入失败，确认不会留下主表、半场项目或孤立组，旧图完整回滚。

- 新路由：`WORKOUT_HISTORY = "workout/history"`；`WORKOUT_DETAIL_PATTERN = "workout/detail?workoutId={workoutId}"`，构造器 `workoutDetail(id)`。原 `workoutEditor(id?)` 保持不变。所有 ViewModel 作用域均为对应 NavBackStackEntry。
- `HomeScreen` 新增可选 `workoutContent: @Composable () -> Unit` 插槽，导航注入训练区域；没有改变其他调用所需参数，没有新增纵向嵌套滚动列表。
