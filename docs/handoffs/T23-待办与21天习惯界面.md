## 实际交付

- 首页双卡下方“今日待办”：完成数、勾选与撤销、点行编辑，添加菜单分“手动待办”“21天习惯”。首页展示前4项，完整清单保留全部项目及历史日期。
- “全部清单 / 习惯”进入独立页面，支持滚轮选日查看旧清单；进行中的习惯可新增、编辑、暂停/恢复、结束。操作按钮使用可换行布局适应窄屏或大字。
- 手动待办只必填名称，日期默认今天，时间默认不指定。编辑草稿用SavedStateHandle保留，保存前不写Room；取消不修改原数据，删除/结束二次确认，忙状态防重复写入，失败保留输入并显示信息。
- 习惯默认每天，可选每N天或每周指定日。开始日算第1天，至start+20结束；第22天隐藏，不再生成，历史待办/完成信息保留。暂停不延长，漏做不重置，21天不表述为保证养成习惯。
- 日期、可选时间全部复用公共`RecordDatePicker` / `RecordDateTimePicker`原生滚轮。待办储存的是本地日期及可选分钟，UTC仅用于适配无时区日历滚轮，不在界面展示偏移或把任务日期换算为瞬时UTC。
- 当前日来自`HomeViewModel.today`；进入今天/清单、Activity恢复、跨午夜时刷新；恢复备份后返回首页也刷新。当日习惯生成由Repository限制为手机当前日期，历史选择或日期跳跃不批量补造过去。
- 设置的备份确认预览补待办/习惯数量与本地日期范围，明确旧版备份中缺少两类数据时全量恢复会清空当前清单/计划。

## 主要文件与接口

- `feature/todo/TodoViewModel.kt`：首页/历史Room Flow、编辑草稿、忙/错误/确认状态及习惯生成。
- `feature/todo/TodoScreens.kt`：首页组件`TodoHomeSection`、管理页`TodoScreen`、全局`TodoDialogs`。
- `MainActivity.kt`：从`container.todos`装配ViewModel，传入同一`homeViewModel.today`及Clock/Zone。
- `ui/navigation/LifelogNavHost.kt`：可选`todoViewModel`参数，原测试调用继续兼容；新增TODOS路由、进入/恢复刷新；`TodoDialogs`置于LazyColumn外，滚动不会导致未保存编辑器消失。
- `HomeViewModel.refreshToday()`：恢复时重新读取手机日期/时区并重排下个午夜。T24的HomeScreen尾部`todoContent`插槽和底部Insets消费保持完整。
- `feature/settings/SettingsScreen.kt`和`values/todo_strings.xml`：预览数量及界面文案。
- 数据结构、Room6/备份v6及迁移由T22交付；本任务按其真实接口接线，没有引入第二套存储。
