以上五类字段通过 RecordTextField 的可选 voiceInput 参数显式显示麦克风，24dp 图标位于 Material IconButton 的至少 48dp 触控区，使用现有主题色、点击反馈和“语音追加”无障碍描述。数字、时间、搜索、自定义饱腹感和自定义训练感受沿用原交互。

点击后委托系统识别界面；成功取返回列表中首个非空候选（系统约定按置信度降序），trim 识别文字后直接追加到当前最新草稿末尾，不替换原文、不连接多个候选、不自动保存。用户可手改或再次分段追加，最后点击原保存按钮。

取消不修改文字；空结果、失败、服务不可用用简短 Toast 提示，键盘仍可使用。一次编辑器仅允许一个未完成请求；等待时当前字段入口变为关闭图标及“取消等待语音结果”，其他语音入口禁用。取消等待只使本 App 请求失效，外部识别界面中的录音结束/取消由服务控制。

语音绕过饮食的 4000 原始输入防护与待办的 take(120)，完整保留超长结果并立即显示超限提示；原保存上限不变，需缩短才能保存。已有超长草稿允许逐步删除及等长改错，普通键盘输入的原有防护保留。草稿仍由原 SavedStateHandle 恢复。

## 接口、权限与联网行为

采用 `RecognizerIntent.ACTION_RECOGNIZE_SPEECH` + AndroidX Activity Result API（`StartActivityForResult` contract / `ActivityResultRegistry`），不使用 `SpeechRecognizer`、第三方 SDK、大模型或付费云服务，不增加依赖。

请求参数为 `LANGUAGE_MODEL_FREE_FORM`、`zh-CN`、最多一条候选、不接收中间结果、`EXTRA_PREFER_OFFLINE=true`。优先离线只是服务偏好，提供方可以忽略；本方案不能保证离线、不能强制选择设备端引擎，也不以系统存在语音输入法推断识别 Activity 可用。

本 App 委托外部识别 Activity，自身不直接打开麦克风，**不声明/申请 RECORD_AUDIO 或 INTERNET**。识别提供方管理其自己的麦克风授权及可能的联网，拒绝授权或服务错误时保持原文字；启动时 SecurityException 也会安全退化。主机合并 Manifest 检查确认未增加录音/网络权限。App 不生成、管理或导出录音文件，也不传递原有描述文字给识别提供方；外部服务的音频处理与联网遵循其自身实现。

Android 11+ 为 `resolveActivity` 能力检测增加且仅增加以下包可见性查询：

```xml
<queries>
    <intent><action android:name="android.speech.action.RECOGNIZE_SPEECH" /></intent>
</queries>
```

每次点击时检测系统实际处理能力，且捕获检测后服务卸载/禁用引发的 ActivityNotFoundException，不硬编码 Google 或任何厂商包名。荣耀无 Google 服务设备若有兼容 Activity 可直接使用；若没有则提示不可用并保留键盘入口。本轮不把未实测的荣耀能力写成支持。如荣耀实测没有可用接口，而主管要求设备内置识别或其他方案，先做服务/隐私/体积/费用评估，由主管决定，不能直接引入云 SDK。

实现前核对的 Android 官方资料（2026-11-12）：

- [RecognizerIntent API：自由描述、候选顺序、离线偏好可能被忽略](https://developer.android.com/reference/android/speech/RecognizerIntent)。
- [Activity Result：重建时独立恢复请求上下文](https://developer.android.com/training/basics/intents/result)。
- [包可见性：检测能力需 queries，仍应捕获 ActivityNotFoundException](https://developer.android.com/training/package-visibility/use-cases)。
- [委托系统识别 Activity 的官方示例](https://developer.android.com/training/wearables/user-input/voice)，示例页面为 Wear OS；本实现的手机接口契约依据上面的通用 API。
- [SpeechRecognizer：直接使用该类才需调用方 RECORD_AUDIO，并需主线程和 destroy](https://developer.android.com/reference/android/speech/SpeechRecognizer)；本任务未采用该类。

## 回调与数据边界

- VoiceInputSession 为每次请求分配 UUID、目标字段和“已启动”标记，单独保存在原编辑器 SavedStateHandle；每请求使用独立 registry key，旧回调不能消费新的请求。
- 回调先消费/清空令牌，再更新最新 ViewModel 草稿；重复回调无效。Activity/进程重建后重新注册同一请求，已启动标记阻止重启识别；加载完成前延后注册，避免恢复结果被加载覆盖。
- 训练绑定放在 LazyColumn 之上；滚动导致备注输入框销毁不会换目标，重排仍按 item.id，删除项目使其请求失效。更新从最新 form/item 取值，避免旧闭包覆盖其他编辑。
- 保存尝试、返回、关闭、切换待办/习惯草稿、删除/归档、进入训练项目选择等使旧请求失效；离开编辑页亦失效。系统识别界面会让宿主暂停/停止，因此不在 ON_STOP 取消。配置变化保留请求，普通离开 composition 取消。
- 结果只走原 ViewModel 草稿。最终保存仍调用原 Repository/PhotoStorage；不修改 Room schema、数据库版本、ZIP 格式、自动 JSON 格式、AppContainer 或导航。
