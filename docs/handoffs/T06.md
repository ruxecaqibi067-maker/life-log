## 实际交付与状态转换

- 首页快捷按钮直接写库：首次读取 Room 完成前禁用；无活动项为「准备睡了」，有活动项为「起床了」；写入中禁用并显示保存状态。固定操作 UUID、界面忙碌保护、事务内检查与唯一 `activeSlot` 索引共同防重复。
- 首页活动卡不按今日过滤，跨午夜仍显示原记录的完整就寝日期时间、时区和未结束状态。结束后同一 ID 转成完成项并归到起床当地日期；不产生第二条记录。
- 「查看作息 / 补录」进入所有作息列表；支持夜间、午睡等多段。点击记录可编辑开始、结束、各自时区；关闭「已起床」可保留/恢复未结束状态。删除需确认，取消不写库。未记录与未结束均不解释为零小时。
- 补录与编辑输入完整 ISO 日期时间（示例 `2026-10-23T07:10`，可包含秒及毫秒）、IANA 时区；夏令时重复时间必须显式填写合法 UTC 偏移，不存在的当地时间被拒绝。已存记录加载时保留原秒、毫秒与偏移；修改日期时间/时区后清空旧偏移以要求重新核对。
- 结束必须晚于开始，重叠阻止保存，边界相接允许。超过24小时需要检查并确认；确认保存原始输入，取消保留表单且数据库不变。首页长时段确认固定最初点击的结束时点及结束时区，等待确认期间不会继续延长。
- 撤销是当前 Activity 生命周期内最近一次快捷操作的反向操作：开始→删除刚创建的活动项；结束→去掉起床时间并恢复原开始时点/时区。撤销有确认，取消无写入；事务内比对整行已存值并重新验证重叠，拒绝覆盖后来编辑或与新活动项重叠。编辑和删除也比对加载时的整行快照。进程重开后的修正入口是编辑/删除；不承诺恢复快捷撤销提示。
- 表单通过 ViewModel + SavedStateHandle 保留轻量输入；离开有修改的表单需确认放弃。未保存表单不承诺跨强制停止/手机重启恢复。SQLite 提交完成后才退出编辑器。
