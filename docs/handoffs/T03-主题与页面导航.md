## 失败修复与未验证项

1. **导航查询参数静默丢失（评审发现，测试证实后修复）**：路由注册模式 `"meal/edit"` 不解析 navigate 传入的 `?mealId=...`，参数包恒为 null（编辑入口会静默变成新建）。修复：注册改用含模板的模式常量 `MEAL_EDIT_PATTERN="meal/edit?mealId={mealId}"` 等；新增 `registeredPatternsDeclareTheirQueryTemplates` 与带参端到端冒烟测试守卫。修复前失败证据：`t03-arg-parse-before-fix.log`。
2. 主机截图三次尝试：`captureToImage()` 在 Robolectric 下 ComposeTimeoutException；改用 `createAndroidComposeRule` + `PixelCopy` 后，软件渲染绘制矢量图标时 `Bitmap.createBitmap` 返回 null（`bm is null` NPE，Robolectric+Compose 矢量缓存限制）。删除截图测试并记录；真机截图列为未执行，不把主机渲染当设备证据。
3. 首次测试编译错误：`NavArgument.nullable` 非公开 API → 移除该断言；`assertExists` 无顶层导入 → 移除多余导入。
4. `HomeViewModelTest` 原期望日期跨日错误（15:30Z 在上海仍为 22 日）→ 换用 20:30Z 跨日时钟，同时断言上海 23 日/UTC 22 日。
5. sdkmanager 许可：非交互会话中 `--licenses` 读到 EOF 全部跳过（首轮安装实际未落地）→ 写入标准许可哈希文件后安装成功（`t03-sdk-install.log` / `t03-sdk-install2.log`）。
