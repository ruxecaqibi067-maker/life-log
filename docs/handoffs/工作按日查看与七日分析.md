## 实际交付

1. 点击首页工作卡中央进入工作记录，默认跟随手机今天，只显示结束归档日属于当天的记录。通过“查看其他日期工作”调用公共年月日滚轮，也可前一天、后一天、回到今天。选择在编辑返回、页面重建后保留，退出记录页后重新进入默认今天。
2. 工作归属复用已保存的 `archiveLocalDate`：完成归结束日，未结束暂列开始日，结束后由原Repository自动归到结束日。不重新归档旧记录，不改变首页或回顾的整段汇总。
3. 新增当天工作时间分布与截至所选日期的连续七日图。0/6/12/18/24时轴标记真实已完成工作区间，多段分开；按手机当前时区自然日裁切。例如26日23点至27日1点，记录归27日，图表26日23–24点、27日0–1点。日图总量因此可能与按结束日归档的首页总量不同，页面明确说明跨夜分日。
4. 七日每行可点击切换日期；当天图附时段文字，时间轴有完整日期、时段和时长语义。无完成段显示“暂无已完成时段”，不当作零工作；未结束只在开始当天标空心点，不推算时长。
5. 复用作息已接受的自然日裁切、DST23/25小时日刻度与Canvas卡片。抽取为中性 `DayTimeAnalysis` / `TimeAnalysisCards`，睡眠与工作各自只将原记录的时间点投影进去；没有把工作转成睡眠记录，标题/说明/测试标签仍各自独立。
6. 历史日期补录预填所选日与当前钟点，仍沿用公共年月日时分滚轮；取消/返回不写入，新草稿重建不漂移。已有编辑保留原起止时区及毫秒，保存、删除、撤销和异常长时段确认继续由原工作接口负责。
7. 当前活动工作编辑、读取错误、撤销入口保留在记录页，确认弹窗仍挂在滚动区外。每条记录保留明显的“查看 / 编辑”边框箭头按钮；记录和两类图由Room Flow在保存、结束、改归属或删除后刷新。
