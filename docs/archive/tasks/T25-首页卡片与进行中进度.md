# T25 首页卡片、进行中进度与快捷区

对应本轮反馈1–4，前置已发布0.1.6/code9 `be27d09`及本轮计划提交。读取[反馈与分工](FEEDBACK-2026-10-26-第二轮界面与饮食照片.md)、AGENTS、STATUS及实际代码。

## 要实现的行为

1. 双卡删除底部“查看/补录”按钮，圆环及卡片中央内容形成可点击区域，进入原睡眠/工作记录页面。目标编辑独立，点击目标不误跳转；中央入口有点击反馈及无障碍描述，至少48dp，不靠隐藏按钮保留旧测试。
2. 进行中时显示即时预览：圆环按“当天已完成时长 + 本次进行中已持续时间”对目标绘制，封顶仅用于图形；明确标记“进行中/本次已持续”，避免将预览冒充已完成记录。停止后以真实保存结果刷新，失败仍保持进行中。跨午夜沿既有结束日整段归档语义，不改数据库/备份或已完成汇总。
3. 预览用注入Clock的真实开始时点计算，不在每次tick写库；在前台按需刷新，恢复前台立即重算，不新增后台服务/闹钟/常亮。无目标/加载/错误不伪造比例，缺记录不表示零；时钟回拨不出现负数，精度/溢出正确。
4. 删除截图中首页工作“开始时间/编辑/撤销”整块区域。工作历史/详情中提供对应活动记录编辑与撤销，取消/错误/长时段确认仍可达。睡眠首页同类冗余操作一并移到作息页，保留错误和必须的确认反馈，不丢撤销能力，不改变工作不黑屏及睡前页直接起床。
5. 四个快捷入口默认展开，提供明确收起/展开开关；收起后不留四按钮高度，不隐藏恢复入口或侵入系统手势区。当前页重建保留选择，新会话默认展开即可；不新增需备份的偏好字段。
