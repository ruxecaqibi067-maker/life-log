## 首页布局与交互

顺序为“今天/日期/设置 → 今日睡眠卡片 → 今日时间线及训练记录按钮 → 时间线”；底部“记饮食、准备睡了/起床了、记运动”和今天/回顾导航保留。睡眠卡片在内容滚动区，不额外固定占用整屏高度。

### 睡眠卡片

- 标题为“今日睡眠”，上方或标题旁清晰显示“期望睡眠：8小时”等目标；提供可辨识的“设置／修改”操作，不使用 UTC、ISO 或 `08:00` 钟点形式表示时长。
- 已记录时长与目标在同一卡片呈现，例如“已记录 7小时20分”“期望 8小时”，附轻量说明“按作息记录计算”；不宣称监测到实际入睡或睡眠质量。
- 图形为**扇形进度图，可用圆环扇形表现**：完整圆表示目标，填充扇形表示已记录时长，剩余为中性底色。使用 Compose Canvas/现有矢量能力，不增加重型图表依赖或栅格图片。
- 有目标且有已完成记录时，比例 `recordedDurationMs / (targetSleepMinutes * 60000)` 限制在0到1；先按毫秒计算比例，再格式化文字。不能把实际和目标当成两个独立饼块（实际/(实际+目标)会误导）。
- 超出目标时图形满圆，文字保留真实值，例如“已记录9小时／期望8小时”；不画多圈、负剩余或新增健康评判。
- 没有目标显示“设置期望睡眠”，可以显示真实记录时长，但不画有含义的达成比例。没有已完成记录显示“暂无已完成记录”并用中性占位，不显示“睡眠0小时”或“还差8小时”。加载、错误和重试各有真实状态。
- 进行中单独显示“作息进行中”；即使开始日在昨天仍可见，不并入完成时长。已有已完成段时仍显示汇总，并注明另有进行中记录。
- 移除首页独立的“查看作息／补录”文字按钮；卡片主体点击进入既有作息记录页，并以小箭头或轻量“查看／补录”提示可点击。目标编辑是独立点击区，点击修改不能误入历史页。未设置目标或无记录时也必须能进入补录。
- 原 `SleepHomeStatus` 同时承担读取失败、重试、进行中编辑、撤销确认和异常长区间确认。必须把这些能力完整接入新卡片或卡片附近的反馈区，不能删除原组件就连带丢失逻辑，也不能保留一份重复作息入口。

### 目标编辑

- 使用“小时＋分钟”的轻量弹窗，表示时长而不是当天钟点；已设置时回填原目标，未设置时编辑器可从8小时开始。目标在用户确认并写入成功前不生效。
- 对接 T18 的1–1440分钟校验；支持例如7小时30分，0小时0分不可保存，24小时只允许0分钟。取消、系统返回、旋转/重建不误写；失败保留输入并可重试，重复确认不重复写入。
- 保存成功后卡片即时更新，重启及备份恢复后从真实设置读取；目标改变不修改睡眠记录。页面不额外强制用户先设目标才能随手记作息。

### 训练记录入口

- 将当前像普通文字的“训练记录／补录”改为明确的按钮，例如复用 `SecondaryButton`，显示训练图标＋“训练记录”＋向右箭头；点击区至少48dp，有按压反馈和按钮语义，不能只改文字颜色。
- 继续进入现有训练记录/补录页面，不新增重复路由；空记录也能点开并新增，返回后仍在今天页。底部“记运动”继续直接新建，区分两种用途。
- 时间线标题与按钮在窄屏/大字体下允许分行，文字不截断，不压缩实际触控区域。

## 可用性与验证

- 沿用 T17 品牌绿、暖中性、字体与圆角；深浅色均清晰，色彩以外有完整文字说明。图表提供包含目标、已记录时长和状态的可读语义，TalkBack不能只读“图片”。
- 360dp宽与1.5倍系统字体下，卡片可换为上下布局，目标/修改/箭头、训练按钮及底部快捷操作可触达；不靠缩小系统字号解决拥挤。
- 主机：`:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest`。补充有行为意义的状态/点击/保存取消/失败重试/午夜切换检查；不为静态圆角或颜色写镜像测试，不放宽旧断言掩盖回归。
- 代表场景：未设置、目标8小时已记录7小时20分、9小时超过8小时、无记录、只有进行中、已完成加进行中、多段含午睡、加载失败、目标编辑取消与失败、补录/修改/删除后刷新。
- 检查扇形图与真实 Repository 汇总一致；例如7小时20分/8小时约占整圆91.7%，不使用虚构固定值做正式展示。真实记录时长不被截断成目标值。
- 在稳定的现有 API34 AOSP 模拟器通过隔离包验证首页→卡片→作息补录/编辑→返回、修改目标、训练按钮→列表→补录→返回；保留睡前页系统返回/撤销、原生滚轮及底部快速记录回归。不可连接设备时明确未执行。
- 提供普通浅/深色、未记录/进行中、超目标、目标弹窗及1.5倍字体截图；主管能直接判断“首页一眼看懂睡眠”“训练入口明显可点”。截图仅用虚构记录，不复制用户附件中的生活内容进仓库。
