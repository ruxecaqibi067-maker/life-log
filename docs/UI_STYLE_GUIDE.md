日期：2026-10-24（Asia/Shanghai）。方向：简洁、温暖、轻量、耐看，让生活记录随手完成。

**当前为实施前规范与页面盘点，尚未应用到界面。** 盘点基线为 `1896715`；本轮 T05“没吃饱”和 T06 新交互仍待主管接受整合。这里的目标色值、排版和组件规则是后续实现约定，不代表代码或设备检查已完成。接受基线明确后，通过正常合并更新 T17 分支，再复核本规范与新界面。

## 1. 使用原则

- 保留品牌绿 `#365E50`，补齐暖中性色和完整深色方案。颜色服务于入口、状态和信息层级，不使用大面积渐变、装饰画或额外动画。
- 默认只强调当前页面的主要操作：编辑页保存，项目选择页选择，恢复预检页明确的覆盖确认。首页三个快捷记录入口维持同级，不增加步骤。
- 保持今天/回顾两个底部主入口，设置仍位于顶栏。记录成功、错误、取消、删除、撤销与返回都沿用已有业务逻辑。
- 内容使用中文和系统字体，字号按系统缩放；无外部字体或新权限。未记录、进行中、空数值与真实零值继续分别表达。
- 禁止为排版修改时间归属、保存校验、照片处理、历史快照、恢复边界或 ViewModel 状态机。T05/T06 的本轮能力按接受交付保留。

## 4. 字体、间距与形状

系统字体，常规正文 Normal，标题 Medium；不使用大面积粗体或人为字间距。中文和单位完整换行。

| 角色 | 拟定字号/行高 | 用途 |
| --- | --- | --- |
| headlineSmall | 24sp / 34sp | 关键弹窗标题；避免在列表反复使用 |
| titleLarge | 22sp / 32sp | 页面标题 |
| titleMedium | 18sp / 28sp | 记录标题、重要时间 |
| titleSmall | 16sp / 24sp | 分区、训练项目/组标题 |
| bodyLarge | 16sp / 26sp | 正文、输入 |
| bodyMedium | 14sp / 22sp | 辅助说明、错误正文 |
| bodySmall | 12sp / 20sp | 非关键时间来源/版本；不承载唯一操作或错误修正方法 |
| labelLarge | 14sp / 22sp | 按钮、选项、时间标签 |
| labelMedium / labelSmall | 12sp / 18sp | 简短非关键标签 |

拟集中于 `ui/theme/` 的间距序列：4、8、12、16、24、32dp。页面横向16dp，主分区间24dp；卡片内16dp，紧凑组内12dp；关联字段8–12dp，图标与文字8dp。用布局分组代替每个元素各画一个框。

形状：小标签8dp、内部组12dp、内容卡/输入框/主按钮16dp、弹窗24dp。照片沿用内容卡16dp；时间线48dp缩略图可用12dp，类别图标可保持圆形。投影默认0dp，边框1dp，使用表面层次分离内容。

所有交互目标至少48dp；主要保存按钮至少52dp高。使用 `heightIn(min=...)`，不固定含文字控件高度。24dp 操作图标位于48dp触控区，图标不替代标签和无障碍说明。

### 状态规则

- 加载：显示现有真实加载状态，不先闪出“没有记录”。有旧内容的刷新失败不清空记录。
- 空白：仅当数据已读且确实为空，显示“这一天还没有记录”或当前列表对应文案；不显示健康判断或0值。
- 错误：正文说明可采取的操作，重试易触达；保留输入及原有字段定位，不压缩进一行。
- 选中：表面色、图标/选中语义共同表达；饱腹感可再次取消，继续允许不选。
- 禁用：保留控件位置和语义，不能以透明背景隐藏入口。
- 保存中：沿用既有 busy 互斥；不新增确认弹窗或提前显示成功。
- 删除/放弃/恢复：统一弹窗形状与按钮层级；保留各自确认和取消边界。恢复“覆盖并恢复”仍明确写出替换风险。

## 7. 小屏、字体与键盘

- 基础布局核对宽度360dp，字体1.0及约1.5倍。应用主题与系统相反的组合另测，不能只测 SYSTEM。
- 对按钮使用最小尺寸和内容自适应；长中文记录/运动名称允许换行。保存、取消、确认、错误修正方法不使用省略号；非关键列表摘要可两行省略，详情提供完整内容。
- 五个饱腹感项使用 FlowRow，约1.5倍字体至少48dp触控；运动筛选/日期操作根据宽度换行。主题三段选项无法容纳时改为完整文字的纵向选项，不缩字或隐藏“跟随系统”。
- 表单保留单一纵向滚动容器；训练逐组仍使用外层 LazyColumn。固定保存区域先处理 IME/inset，避免双倍底部空白。
- 对话框正文可滚动、操作区独立可达；屏幕旋转、系统字体变化重建后按已有 SavedState 约定恢复，不新增草稿持久化承诺。
