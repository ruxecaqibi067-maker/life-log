## 工作交互

- 首页工作卡片内显示“开始工作”；有未结束项时切为“结束工作”，状态读取真实Room。加载/失败时不允许误触发新开始，读取失败与空记录分开，有重试。
- 点击开始成功后留在首页，显示“工作进行中”；点击结束只在持久化成功后更新已完成时长。忙碌防重复、写入失败重试、异常长区间确认及安全撤销沿用数据契约；失败不能伪报结束。
- 休息时结束当前段，回来再开始另一段；页面轻量说明“一天可以记多段”。本轮不增加独立暂停状态、项目任务、工资/考勤或番茄钟。
- 卡片有明显“查看／补录”入口，进入工作历史和编辑页；支持开始/结束完整日期时间、未结束开关、查看、补录、修改和确认删除。时间选择优先复用现有成熟选择器或组件，避免ISO/T/UTC技术输入，不新增另一套易错轮盘算法。
- 编辑/取消/返回/页面重建保留正确草稿，失败保留输入；旧毫秒/时区/归档在未明确改动端点时保持，沿用Repository的重复/重叠及长区间规则。
- 退出App或系统熄屏不自动结束；重开首页恢复进行中。睡眠与工作状态独立，启动工作不进入睡前路由、隐藏系统栏、改亮度或误结束睡眠。

## 首页双卡片与目标

顺序为“今天/日期/设置 → 睡眠卡片 → 工作卡片 → 今日时间线/训练入口 → 时间线”；均在可滚动内容中，底部既有三个快速记录与今天/回顾导航保留。工作开始/结束放在工作卡内，避免把四个按钮强塞到原底栏。

- 工作卡片标题“今日工作”，显示“期望工作：8小时”等目标及“已记录5小时”等真实已完成时长；工作目标独立编辑，不复用或修改睡眠目标。
- 目标首次未设置；编辑可从8小时建议开始，小时＋分钟表达时长，确认写入成功后生效。支持1–1440分钟、null未设置（若有清除入口）；取消不写入，非法/失败保留旧值并能重试。
- 图表与睡眠扇形进度同一视觉规则：完整圆为目标，填充 `recordedDurationMs/(targetWorkMinutes*60000)`，0–1封顶；超过目标图形满圆，文字保留真实时长。不能用工作与睡眠相加来分配同一饼图。
- 未设置目标不伪造进度，无已完成记录显示“暂无已完成工作记录”，不写工作0小时/没工作；全局进行中单独提示，不加到完成总量。加载、失败、陈旧数据与重试清晰。
- 默认与睡眠相同，跨夜完整归结束日；卡片或历史提供轻量口径说明“按结束日统计”。当天多段相加，不自动扣午休。
- 先沿用T19的布局；窄屏/大字体以纵向紧凑卡片为主，宽屏如采用双列要让文字和点击区清晰。数据仍独立；两个卡片都能看到目标、时长和状态，不能因塞入一屏裁掉操作。
- 如抽取通用扇形/目标对话框，只抽视觉和明确参数；睡眠文案、工作文案、两类状态机/Repository仍各自负责，不为复用把工作混入SleepViewModel。

## 时间线、回顾与备份预览

- 在T20数据已合入后新增第四种只读时间线类型 `TimelineKind.WORK` / `TimelineEntry.Work`，原MEAL/SLEEP/WORKOUT持久化含义不变，不把work误写成workout训练。
- 时间线Repository接入工作按日Flow；已完成工作按结束时点、活动项按开始时点排序，沿用稳定ID规则。回顾可选日期纳入仅有工作记录的日期，补录/改日/删除后同步更新。
- 今天与回顾显示工作图标/标题/区间/记录时长或进行中状态，点击到工作编辑/详情；四类计数、空状态、错误与导航都处理新类型，不放弃穷尽分支以漏掉工作。
- 备份预检/确认/成功/回滚相关显示纳入工作记录数、时间范围、进行中提示和两个目标；只有工作数据时可理解为有效备份。具体预检/恢复行为继续交给T20及既有控制器，不能写文案宣称保存但实际未纳入快照。
- 保存或恢复成功后，两张卡片及时间线从Flow刷新；取消预览/错误恢复不得导致两类目标或原记录丢失。
