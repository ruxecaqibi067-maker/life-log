## 前置与仅读输入

- 核对项目当前 Git 基线和环境检测结果；当前规划目录没有可运行的 Gradle 工程，不能声称已有构建通过。

## 可写文件范围

- 根 Gradle 配置、Wrapper、Version Catalog、`.gitignore`；`app/` 的空工程构建文件、Manifest、启动 Activity 和必要资源。
- `app/src/main/java/com/personal/lifelog/` 下的 Application 与手动 `AppContainer` 壳；本包交接文件。
- 新增 `docs/ENVIRONMENT.md` 记录实际工具链；工具链变更写交接，共享文档改动按 `WORKFLOW.md` 处理。

## 具体工作

- 检查现有 Android Studio/JDK/SDK/adb；仅安装或配置实现所必需的缺项，不覆盖用户已有设置。
- 选择并锁定相互兼容的稳定工具链、SDK 与依赖版本；写明来源、实际路径和选择理由。
- 建立单 `app` 模块、固定命名空间与包名；不引入 Hilt、网络服务或额外业务模块。
- 创建可启动的极简 Compose 页面，预留手动依赖容器；业务功能仍为空。
- 排除本机路径、密钥、产物、用户数据；保留可复现构建所需的 Wrapper 文件。

## 本包不做

- 不实现饮食、作息、运动、照片和备份，不以占位页面表示业务已完成。
- 不生成正式签名、不发布远端仓库；不改主管状态表。

## 检查命令与证据

- 配置完成后运行 `java -version`、`adb version`、`.\gradlew.bat --version`，记录真实输出。
- 运行 `.\gradlew.bat assembleDebug` 和 `.\gradlew.bat lintDebug`；命令不存在或失败均原样记录。
- 如已有设备或模拟器，记录 `adb devices` 与空页面启动截图；没有设备时标明未执行。
- 记录 APK 路径、工具链版本和 Git 差异；不把生成产物提交进 Git。

## 完成条件与交接

- 干净检出后的环境说明足以复现空工程构建；构建和静态检查有真实证据。
- `docs/handoffs/T01.md` 写明提交、改动、版本/路径、执行命令、失败/未执行项和 T02 入口；主管决定是否验收。
