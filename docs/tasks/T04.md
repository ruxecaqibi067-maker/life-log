## 具体工作

- 封装 Photo Picker 与兼容回退，拍摄使用系统相机和限定目录的 FileProvider。
- 将选图/拍摄结果解码校验、按采样缩放、纠正方向并落到应用持久目录，数据库使用 `generationId/photoId.jpg` 相对引用。
- 区分待处理、待引用和正式照片；取消、复制失败和数据库失败各自有清理规则。
- 保留正在使用的引用，处理原相册照片删除、进程重建与暂存文件遗留；不依赖图库 URI 长期有效。
- 把阻塞 I/O 放后台执行；限制解码资源，避免整张大图导致内存溢出；按路线处理 EXIF 和位置元数据。

## 本包不做

- 不申请整库相册、联网或定位权限；不做 CameraX 自定义相机、AI 食物识别。
- 不将 cache 中的临时照片当成已保存正式数据，不清理仍被有效记录引用的图片。
