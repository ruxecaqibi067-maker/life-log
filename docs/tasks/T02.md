## 具体工作

- 将三类记录、运动定义、训练条目、逐组记录、照片引用及 Room `AppSettings` 单行设置表映射为约定契约；v0.1 不引入 DataStore。
- 一开始就落实稳定 ID、创建/修改时间、时间点与时区、可空数值、排序、历史动作快照和 `generationId/photoId.jpg` 媒体相对路径。
- 为备份保留必要字段与版本兼容边界；完整运动定义库必须可导出，不能只靠已用动作反推。
- DAO 与 Repository 明确事务和唯一未结束作息约束；校验规则集中，注入 Clock 便于测试。
- 配置 schema 导出与迁移策略；禁止在正式用户数据路径使用破坏性回退。

## 本包不做

- 不实现页面、照片处理或 ZIP 导出；不另造与路线文档不一致的时间/单位协议。
- 不把空值默认为零，不根据未记录推断没吃饭、没运动或零睡眠。
