# T23 每日待办与21天习惯界面

基线：`ec005a5`，独立工作树`life-log-t23`；依赖T22 Repository和T24首页插槽。T23拥有新增feature/todo、MainActivity/导航路由、设置页备份新计数；HomeScreen/双卡由T24维护。

## 用户操作

- 首页睡眠/工作卡下方显示今日待办、完成数与添加入口。可直接勾选/撤销，点击编辑、确认删除，区分空白、加载和失败。列表长时跟随首页滚动，底部四个快捷入口保持可达。
- 手动创建只需标题，默认今天，可选日期/时间。新习惯也只需标题，默认今天起每天一次，可自定义每N天或每周指定日，并可编辑、暂停/恢复、归档。
- 习惯明确为21自然日计划：第1天为开始当天，第22天从进行中消失，停止生成；保留既有待办、完成与历史日期查看入口。漏做或暂停不重置，不宣传21天保证养成。
- 日期/钟点统一公共RecordDatePicker/RecordDateTimePicker原生滚轮；未确认不写入，不新增通知/服务/网络依赖。纯数字间隔不强制时间滚轮。
- ViewModel跟随HomeViewModel.today与生命周期刷新/生成当天数据；不在Compose重组中执行重复写入。错误可见且可重试，保存失败不退出或丢草稿。
- 设置备份预览准确展示待办、习惯及本地日期范围，旧格式显示0，明确全量替换。

## 交付

复用现有简洁主题/组件，点击目标至少48dp，长标题换行，大字体不裁切。使用真实接口做少量必要状态检查/编译，独立分支提交和交接；不修改中央STATUS、数据格式、版本或APK发布。与T24协调NavHost底部Insets区域，避免双写。
