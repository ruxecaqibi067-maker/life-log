## 可写文件范围

- `app/src/main/java/com/personal/lifelog/feature/settings/` 的备份恢复页面、ViewModel 与状态。
- 导航/SAF 启动适配、公共进度/错误组件和必要 UI 测试；本包交接文件。
- 引擎只允许必要缺陷修复并说明影响，不在页面另写备份和恢复逻辑。

## 具体工作

- 设置中提供导出、选择备份、预检、数量/时间范围预览及明确全量覆盖确认。
- 选择、预览和确认之前均无覆盖；说明恢复前自动回滚备份结果，不让用户误以为只是追加。
- 显示真实的执行状态，防重复触发；按引擎能力区分可取消阶段与提交阶段。
- 成功仅在引擎确认完整提交后显示，Room `AppSettings` 与记录同步恢复；提交前失败提示旧数据未变，提交后清理失败提示已恢复/清理待重试，不能自行回退旧库。
- 页面重建或切后台后可查询真实任务结果，完成恢复后今天/回顾刷新到有效数据集。

## 本包不做

- 不提供未经实现的云同步、定时备份或任意合并选项。
- 不用漂亮成功动画代替导出文件写入/恢复提交的真实结果。

- 核对预览取消原库不变，成功后页面刷新，回滚结果和错误说明与引擎事实一致。
- 提供完整录屏与界面重建/后台返回证据；缺少设备时如实记录待 T15。
