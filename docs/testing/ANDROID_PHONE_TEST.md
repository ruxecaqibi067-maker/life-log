# Android手机实机测试

本轮本地测试：随手记0.1.6，versionCode8；包名 `com.personal.lifelog`。适用于支持 APK 安装的 Android 9 及以上手机。先用虚构数据检查；不同品牌系统交互和性能仍需实测。

本轮APK只由电脑本地`artifacts/phone-test/随手记.apk`复制到手机，GitHub仍为0.1.4，后续远端APK更新需用户明确要求。重点见[本轮说明](../releases/0.1.6-local.md)。旧清单中卡内工作按钮和纵排布局已改为底部2×2及并排双卡；备份现在导出v6、可读v1–v5。

## 本轮新增功能先测这些

| 操作 | 预期 |
| --- | --- |
| 看首页、上下滚动、系统字体调大 | 双卡下有今日待办，卡内无“按结束日统计”；底部四按钮紧凑且可点，不压系统手势区 |
| 只填“测试待办”保存，勾选/撤销后重开 | 标题和完成状态持久保留，完成数同步 |
| 编辑日期/可选时间，先取消再确认 | 使用年月日/时分滚轮；取消无变化，确认后到对应日期；不设置时间不伪造00:00 |
| 删除一条待办，刷新/重开 | 已删除项不复活；删除确认取消时保留 |
| 仅填标题创建习惯 | 默认今天每天一次，今日出现一条；重开不重复生成 |
| 创建“每2天”和“每周指定日”，暂停/恢复 | 仅符合日程的当天生成；暂停不新生成，已有实例仍保留 |
| 用开始日在20天前的虚构习惯查看周期，再用21天前开始的习惯对照 | 前者是第21天且当天符合频率时可生成，后者第22天不在进行中、不生成；已有待办/完成历史仍可看，不需修改手机日期 |

同签名覆盖安装后，先检查原饮食/照片/作息/工作/训练/目标还在。不要为模拟到期更改日常使用手机的系统日期，也不要用真实数据尝试旧备份全量恢复。

## 1. 下载与安装

本轮把电脑上的`artifacts/phone-test/随手记.apk`经USB等方式复制到手机，按同目录安装说明核对0.1.6/code8，再覆盖安装。GitHub[公开下载页](https://github.com/ruxecaqibi067-maker/life-log/releases/tag/v0.1.4)保留0.1.4，不能用于本轮新功能测试。

1. 在手机文件管理器中打开 APK，按系统提示允许本次安装来源，完成后打开「随手记」。不需要账号或开发者模式。
2. 若已安装旧版，先在旧 App 的设置中导出备份，再直接覆盖安装；不要先卸载或清除数据。
3. 若提示签名冲突，保留旧安装和数据并反馈。以前的 debug 包不能直接被长期签名包覆盖，`.qa` 也属于独立安装；已有记录应先导出备份并确认可恢复。
4. 在手机「关于手机」记下 Android、厂商系统 版本；同时记录测试日期、App 版本和字体大小。

## 2. 第一轮操作清单

建议按顺序测试；每步记录“通过／失败／未测”。仅使用自己创建的虚构记录和无隐私测试照片。

| 步骤 | 实际操作 | 应看到的结果 |
| --- | --- | --- |
| 1 启动与离线 | 打开 App，切飞行模式后再打开 | 今天、回顾、设置可访问；不要求登录或联网 |
| 2 文字饮食 | 记录“测试午餐：面条”，饱腹感留空；编辑为“没吃饱”，再改为自定义“还想再吃一点” | 可以保存；首页、详情、回顾一致；自定义空白或超过 40 字时有提示 |
| 3 照片饮食 | 分别尝试相册导入、系统拍照；只留一张照片不填文字保存 | 保存后图片可打开，退出重开仍存在 |
| 4 照片取消 | 写一句文字，进入拍照/相册后取消；再撤销一张未保存照片 | 不产生空记录，原输入仍保留；离开有改动的草稿时能选择放弃 |
| 5 作息 | 点“准备睡了”，从睡前页系统返回；退出 App 再进入，随后点“起床了” | 保存后才出现纯黑时钟和三句短句；返回不结束，未结束状态保留，只生成一段记录 |
| 6 训练 | 新建一次训练，加入跑步与卧推；跑步数值先留空 | 仅记录动作也可保存，一场训练显示为一条记录 |
| 7 力量组 | 卧推填写 40 kg × 10 次，复制后改成 45 kg × 8 次，再加只填 6 次的一组 | 三组独立保存；改副本不改原组；空重量不会显示成 0 kg |
| 8 自定义项目 | 新增“测试动作”，选类型，保存训练；随后改名、隐藏该项目 | 旧训练保留原名称快照；新建默认列表不出现隐藏项目 |
| 9 回顾与编辑 | 选择昨天，补记或修改记录日期；编辑、取消删除、确认删除各一次 | 记录按日期移动；取消不丢数据；删除不影响其他记录 |
| 10 字体与键盘 | 切深色模式、调大字体，打开逐组输入并滚动 | 主要按钮可点、文字可读；保存和删除不被键盘挡住 |
| 11 重启 | 保存带照片记录并开始一段未结束作息；退出后重启手机 | 记录、照片、主题和未结束作息仍在 |

作息补录/编辑现在使用中文日期卡和年月日、时分滚轮。请额外检查：打开滚轮取消后原值不变；23:50 到次日 07:10 显示 7 小时 20 分；切换月份后日期有效；保存旧记录不发生时间偏移；关闭“已起床”后不再显示起床时间。时间与时区来自手机系统，不需要填写技术字段。

本轮界面统一后，请额外查看明暗主题、六个饱腹感选项、自定义输入、主题选择及原生日期/时间弹窗。睡前页保持纯黑，离开后系统栏正常恢复；等待系统自动熄屏，不应被 App 强制常亮。

## 本轮重点：睡眠目标与黑屏起床

1. 首次目标未设置；点设置，输入8小时后取消，应仍未设置。再次保存8小时，退出重开后保持。
2. 补录昨夜23:50至今天07:10，今天显示7小时20分，目标8小时的扇形约91.7%；补录午睡后叠加。超过目标时图形满圈，文字保留真实时长。
3. 点击卡片“查看/补录”应到作息记录；旧的单独“查看作息”入口已合并。训练记录有边框、图标与箭头，可点击进入。
4. 点击“准备睡了”，黑屏页底部应显示“起床了”；直接点击后回首页，进行中消失，完成时长刷新。再开始一次，系统返回应保留进行中，首页仍可起床/撤销。
5. 无完成记录时不显示零睡眠；进行中不加到已完成量。小屏、大字体、深浅色下目标、按钮、图表和键盘都应可读可点。

## 本轮重点：工作时间与双卡

1. 向上滚动找到“今日工作”，首次工作目标未设置；保存8小时，睡眠目标保持原值。再尝试取消、非法0分钟和清除工作目标。
2. 点击“开始工作”应留在普通首页，显示“工作进行中”和“结束工作”，不进入黑屏；退出App并重开，进行中仍在。结束后同一条记录完成，图表及时间线更新。
3. 补录今天9–12、13–15两段，应共5小时，8小时目标显示约62.5%；相邻允许，重叠拒绝。只有工作记录的日期也可在回顾选择。
4. 打开“查看/补录”及“查看/编辑”，检查原生时间滚轮、取消、修改、删除取消/确认与撤销。跨夜23–次日01整段归结束日，长于24小时需确认。
5. 开始工作后仍可操作原饮食/训练；就寝进入睡前黑页、黑页起床后工作状态独立。深浅色、大字体、目标键盘及滚动中主要按钮应可触达。
6. 导出包含工作及两项目标的备份，预览核对工作数、目标和进行中提示；先取消检查记录不变，再用虚构数据验证确认恢复与回滚。

## 3. 备份恢复测试

恢复会全量替换当前记录和设置。此轮只使用虚构数据；ZIP 未加密，请保存在自己控制的位置。

1. 在设置选择“导出备份”，保存为 A.zip，等待“备份已导出”。确认手机文件管理器能找到文件。
2. 再新增一条“恢复前临时记录 B”。
3. 选择“从备份恢复”并选 A.zip，查看数量预览后取消。B 应仍然存在。
4. 再选 A.zip，明确点击“覆盖并恢复”。B 应消失，A 中的四类记录、照片、组和设置应保留。
5. 导出最近的回滚备份为 R.zip，再按预览/确认流程恢复 R.zip。B 应回来。
6. 重新导出一次并保留副本；同时测试文件选择器取消，不应改变 App 数据。

本版导出v5备份，可读取v1–v4旧备份；旧App不能读取v5。保留旧ZIP，检查运动感受、自定义饱腹感、两个目标及工作记录的导出/恢复；取消或失败不应改变现有记录和目标。

出现失败、卡住或“需要恢复检查”时，保留当前安装和备份，记录页面提示后反馈；不要通过卸载或清除数据来重试。
