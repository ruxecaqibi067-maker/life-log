## 用户可见变化

1. 就寝/起床显示中文日期和 24 小时时分；点击后以原生滚轮选择年月日、时和分，有确认与取消。
2. 界面去掉时区、UTC 偏移、T、秒和毫秒，时间/时区自动来自手机系统。
3. 未修改旧时间时保留原时间点、两端时区、毫秒和归档；分钟选择只是视图，不迁移历史数据库。明确修改时才保存新分钟。
4. 继续支持跨夜、午睡、多段、未结束、长区间确认、重叠校验、删除和取消。
5. 下载文件为 `suishouji-0.1.2.apk`，安装后显示「随手记」。包名和长期签名保持，versionCode 从 2 增至 3。
6. 为 Android 9 提供跟随 App 明暗模式的原生 NumberPicker 主题；在不支持公开 textColor setter 的系统上保持数字可读。对 App/系统主题相反的两种情况补充对比度回归。

没有修改 Room schema v1、备份格式 v1、记录 Repository 或权限，也没有添加依赖、自动更新提醒、服务器或 Google 服务。

## 兼容性判断与限制

- minSdk 28、targetSdk 36、无 maxSdk；没有厂商/品牌限制。targetSdk 不是最高系统版本。
- 生产依赖不含 GMS；Photo Picker 不可用时回退 ACTION_OPEN_DOCUMENT。
- 无 ABI 过滤/架构拆包；最终 APK 含 AndroidX 图形库的 ARM64、ARMv7、x86、x86_64 四种 ABI。ELF LOAD 段及 APK ZIP 的 16 KB 静态对齐检查通过，未冒充 16 KB 手机实测。
- 使用标准相机、FileProvider、SAF、Room 和 Compose；这些是面向不同 Android 手机的设计依据。
- 实测矩阵仍包括主机 SDK 28/33 和模拟器 API 37；荣耀 200 Pro及其他品牌真机、相机/图库/SAF、性能、一周自用待补。没有依据声称“绝大多数手机均已实测通过”。

[通用手机测试清单](../testing/ANDROID_PHONE_TEST.md) 用于收集型号和系统版本。原有验收报告与失败日志保留，不将此前的失败重写为通过。具体资料在本地被忽略的 `artifacts/supervisor-v0.1.2/`，私钥、密码、用户备份及原始数据不上传。

GitHub 上传和重命名接口均会自动移除中文附件名。附件使用 suishouji-0.1.2.apk，下载页标签和安装后仍显示「随手记」；本地同时留存相同字节的中文文件名副本。
