# 待办与21天习惯规则

2026-10-26用户需求；T22负责数据、T23负责界面，T24提供首页位置。这里集中保留产品规则和资料依据，避免重复过程记录。

## 自动生成与自动结束

| 情况 | 行为 |
| --- | --- |
| 新习惯 | 输入标题即可，今天开始，默认每天一次，可选钟点但不通知 |
| 自定义频率 | 每N天（从开始日锚定）或每周指定日，最多在21天窗口内生成 |
| 周期 | 开始日为第1天，开始日+20为第21天；第22天从进行中隐藏且停止生成 |
| 暂停/漏做 | 不生成暂停期间实例、不延期、不重置；恢复仅在剩余原窗口内生效 |
| 进入某日 | 只有手机当天会生成；不补造未打开的过去日期、不预造未来 |
| 多次进入/重开 | 同一习惯同一原生成日只保留一个实例 |
| 修改/删除 | 已生成待办保留快照；单条可改日期/标题/完成。删除保留内部墓碑以防自动复活 |
| 到期/归档 | 停止生成，已有待办和完成历史保留，日期查看仍可找到 |

待办/习惯日期为本地日历日期，可选钟点仅保存当天分钟；无钟点并不等于00:00。21天自动结束不是自动删除历史数据，也不是“完成21次”的计数器。

## 默认规则的依据

研究者Pippa Lally在[萨里大学2026年访谈](https://www.surrey.ac.uk/news/does-it-really-take-66-days-form-habit-we-asked-expert-dr-pippa-lally)中说明，习惯形成所需时间差异很大，不能用一个固定天数保证结果；清楚规划何时、何地执行有帮助。本App因此采用容易理解的固定日程，默认每天，可让用户按实际生活调整。

“21自然日后自动结束”是用户指定的产品周期，不是科学结论。App不评价是否已真正养成习惯，不添加惩罚或补签压力，也不据未打勾推断用户没有完成现实中的行为。

本轮只在打开/恢复App及跨日时按需生成；“自动”不承诺后台通知或关闭App时持续运行。
